# 贪吃蛇 (Snake_v3)

经典贪吃蛇小游戏，纯前端单页应用，无需安装，打开网页即可游玩。

## 在线试玩

https://keniswong.github.io/Snake_v3/

## 功能

- 键盘控制：方向键或 `W` `A` `S` `D` 移动
- 触屏控制：在画面上滑动，或点击屏幕方向按钮
- 暂停：空格键或 ⏸ 按钮
- 速度等级：每吃 5 个苹果提升一级，速度逐步加快
- 最高分：保存在浏览器本地，刷新页面后仍然保留
- 自动暂停：切换标签页、切换应用或锁屏时自动暂停

## 操作说明

| 操作 | 电脑 | 手机 / 平板 |
|---|---|---|
| 开始游戏 | 回车 或 空格 | 点击“开始游戏” |
| 移动 | 方向键 / WASD | 滑动画面 / 点击方向按钮 |
| 暂停 / 继续 | 空格 | ⏸ 按钮 |
| 再来一局 | 点击“再来一局” | 点击“再来一局” |

## 本地运行

1. 下载或克隆本仓库。
2. 用浏览器直接打开 `index.html` 即可。

## 技术说明

- 纯 HTML、CSS、JavaScript，单文件，无构建步骤，无后端
- 使用 Canvas 绘制画面
- 使用 localStorage 保存最高分
- 托管于 GitHub Pages，自动提供 HTTPS
